Como usar no computador:
Abra o arquivo index.html.

Como usar no iPhone:
A versão precisa estar hospedada em um endereço HTTPS.
Depois abra no Safari e use Compartilhar > Adicionar à Tela de Início.

Nesta versão, os dados ficam salvos no navegador do aparelho.
