# Plano de Vida

**Organize seu presente. Construa seu futuro.**

Versão responsiva para desktop e iPhone.

## Arquivos
- index.html
- style.css
- script.js
- manifest.webmanifest
- sw.js

## Como publicar no GitHub Pages
1. Substitua os arquivos antigos do repositório pelos novos.
2. Faça o commit.
3. Aguarde o GitHub Pages atualizar.
4. No navegador, use Ctrl + F5 para forçar a atualização.
5. No iPhone, feche e abra novamente o app instalado.
